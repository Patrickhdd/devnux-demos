# Devnux demos

Working demo projects by [Devnux](https://devnux.tech). Each one runs locally with a single `docker compose up --build`, has tests that run on every push, and was planned with [Spec Kit](https://github.com/github/spec-kit) (look for `.specify/` and `specs/` in each folder).

| Demo | What it shows | Stack |
|---|---|---|
| [Clinic booking](clinic-booking/) | Patients book visits, doctors run their week. Double booking is blocked by the database itself, tested under concurrent load. | Java 21, Spring Boot 4, PostgreSQL, React, Docker |
